# Decisions and Defaults

> Design status: MVP — Step 3 of 9, approved
>
> Implementation status: NOT STARTED

| ID | Decision or default | Status |
|---|---|---|
| D-13 | The sitemap shows **screen cards with their main content only**, grouped by area. Actors (drawn as people) connect to the areas they use. Solid lines mean parent → child screen; dashed arrows mean "actor uses". | User-approved |
| D-14 | Navigation: Customer uses a **top bar** (few pages, like a help-centre portal); Staff and Administrator use a **left sidebar** with a top bar for the account menu. | User (option A) |
| DF-20 | Ticket details are **full pages**, not modals, because the conversation can be long. Create/edit forms and confirmations are **modals** on their list page. | Default pending confirmation |
| DF-21 | Routes are logical paths; the router mode (history or hash) is chosen in Step 7. | Default pending confirmation |
